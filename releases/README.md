# 发布版本目录

本目录在 Git 中保存发布说明和不含私有配置的版本目录；固件二进制和实机证据保存在工作区 `.local/releases/`，通过工作区 `releases/` 入口访问。

- [固件版本目录](catalog.toml)：两块板的 2.5.23 版本、源码快照和二进制大小、SHA-256。
- `latest-xiaozhi-path.txt`：OLED 板的本地最新发布目录指针。
- `latest-sp-esp32-s3-1.28-box-ai-lan-path.txt`：圆屏板的本地最新发布目录指针。
- `releases/catalog.toml`：工作区中的目录链接，对应 Git 中的 `releases/catalog.toml`。

目录链接中的本说明也可通过工作区 `releases/README.md` 阅读；从该位置查版本目录时使用同目录 `catalog.toml`。原发布包、私有清单和验收证据继续留在各版本目录，不将其完整复制进 Git。
